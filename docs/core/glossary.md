# Glossary

Artistic and theoretical terms. Technical terms of the Max patch are in
[../../other/CONTEXT.md](../../other/CONTEXT.md).

Status: **settled** = fixed usage; **tentative** = working term, may change.

| Term | Meaning | Status |
|---|---|---|
| **la harpe Éliane** | The instrument. See [identity.md](identity.md) for spelling rules. | settled |
| **feed-forward** | Excitation chain with no signal path back from string to electronics: oscillator → magnet → string. Contrasted with feedback. | settled |
| **feedback** | (In this context) a loop where the string's vibration is picked up and fed back into its own excitation. Not used in la harpe Éliane. | settled |
| **modular array / module** | La harpe Éliane is one instrument: a modular array of strings, grouped in modules (currently two four-string modules) that can be arranged and distributed throughout a space. Avoid "two instruments". | settled |
| **voice** | One string with its magnet and synthesis engine. Eight in total. | settled |
| **partial / inner voice** | One of the eight sinusoidal components of a voice's drive signal. | settled |
| **seizing up** | A string abruptly ceasing to resonate under a drive that previously sustained it. | tentative |
| **fragility** | The instrument's tendency toward unpredictable response, taken as an aesthetic and performative condition rather than a defect. | tentative |
| **presence** | The constant attention fragility demands of the performer. | tentative |
| **restraint** | Not doing too much; the counterpart of presence. | tentative |
