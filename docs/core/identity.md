# Identity

## Name

**la harpe Éliane**

- Lowercase throughout except the **É** — French capitalisation.
- **La harpe Éliane** only when it begins a sentence.
- *la harpe*, not *l'harpe*: *harpe* takes an aspirated h, so there is no elision.
- In plain-ASCII contexts (filenames, URLs) where the accent cannot be used:
  `la-harpe-eliane`.

## Namesake

Named after **Éliane Radigue**. The name carries a double reference:

1. **The ARP 2500** — the modular synthesizer at the centre of Radigue's
   electronic drone work. *harpe* / ARP.
2. **The bowed harp** — Radigue's use of bowed harp in her later
   acoustic work.

> **Open —** cite the specific Radigue works/recordings for both references
> (ARP 2500 period; bowed-harp work and performer). See [theory.md](theory.md).
